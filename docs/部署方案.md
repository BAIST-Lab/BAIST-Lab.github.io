**GitHub Pages 托管**

- **优点：**免费、稳定、部署和更新简单，直接用 Git +Decap 表单式管理成员/论文/成果等内容；不需要自己维护服务器、Nginx、HTTPS 和公网访问。
- **缺点：**主要适合静态网页，不能直接运行 Python 后端、数据库或模型推理服务。

**实验室服务器部署**

- **优点：**自由度高，可以运行各种后端、对外提供API等。
- **公网访问：**如果服务器有公网 IP，可以直接开放；如果没有，需要使用 Cloudflare Tunnel 等方式让公网访问（需要长期维持Cloudflare进程）。
- **缺点：**需要自己维护 Nginx、HTTPS、进程和安全，公网开放后会增加被扫描和攻击风险；主页状态可能受服务器重启、网络策略和端口限制影响。

**域名绑定：**

无论哪种方式，都需要购买域名。两种方式可以绑定为固定域名（例如STlab.com）
